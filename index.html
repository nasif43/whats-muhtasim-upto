R&D Findings — Channel Expansion (Oct 2026)
🟣 Viber

~$100/month for API key via Viber Business partner programme. Webhook uses HMAC-SHA256, rate limit 500 req/10s. Defer until client confirms budget.

🎵 TikTok Messaging + Comments

Possible but requires TikTok Developer App approval + DSPR maturity review (data inventory, privacy notice, subprocessor list). LLMs must be declared as subprocessors. Reply window 48h. Architecture already supports it — next step is to connect the channel.

💙 Meta Post Comments

Can reuse existing Meta webhook infrastructure. Comments on posts already trigger events our Meta App is approved for. Needs a new handler and "reply to comment" outbound path.

🔴 AI Agent Removal

Per latest client requirements the AI auto-reply agent is being removed. Platform shifts to a fully human-operated inbox. LiteLLM proxy and e-com session handling will be stripped out.
